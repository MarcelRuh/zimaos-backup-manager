# Contributing

## Regeln

1. Keine erfundenen ZimaOS-API-Endpunkte.
2. Keine Secrets committen.
3. Produktive Pfade ohne Mock-Daten.
4. Tests für Auth, API-Client, Monitor-Übergänge und Discord mitliefern.
5. Deutsch oder Englisch in Issues/PRs ist ok; UI-Strings beider Sprachen pflegen.

## Workflow

1. Fork / Branch
2. Änderungen + Tests
3. `go test ./...` und `npm test` / `npm run build`
4. PR mit ausgefüllter Checkliste
