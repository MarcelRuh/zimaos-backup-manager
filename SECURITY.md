# Security Policy

## Supported versions

Security fixes target the latest release branch.

## Reporting a vulnerability

Bitte **keine** öffentlichen Issues für Sicherheitslücken öffnen.

Melde Probleme privat an den Repository-Maintainer (GitHub Security Advisory oder private Kontaktmöglichkeit des Owners).

## Hinweise

- Webhook-URLs und API-Tokens niemals in Issues/Logs posten
- Nach Verdacht auf Leak Tokens/Webhooks sofort rotieren
